# ✈️ Travel Planner Web

나만의 여행을 계획하고 기록할 수 있는 개인 여행 플래너 웹 프로젝트입니다.

가고 싶은 여행지를 등록하고, 여행 일정과 메모, 사진 등을 한곳에서 관리할 수 있도록 직관적이고 편리한 웹 화면을 구현하고 있습니다.

## 🖥️ Main Page

여행 목록과 여행 추가 영역, 여행 준비 가이드를 제공하는 메인 화면입니다.

- 사이드바를 통한 메뉴 이동
- 등록된 여행 정보 카드 형태로 표시
- 새로운 여행지 추가 영역
- 여행 준비를 위한 안내 카드 구성
- 그리드 및 리스트 보기 아이콘 배치

## 📚 Main Features

### 1. 여행 관리
- 여행지 및 여행 정보 등록
- 여행 제목과 국가, 도시 표시
- 여행 기간 표시
- 여행별 일정, 메모, 사진 개수 표시

### 2. 여행 메뉴 구성
- 여행 홈
- 지도
- 일정
- 메모
- 앨범

### 3. 여행 준비 가이드
- 가고 싶은 장소 모으기
- 기억해야 할 정보 메모하기
- 여행 사진과 추억 기록하기

## 🎯 Goal

HTML, CSS, JavaScript를 활용하여 실제로 사용할 수 있는 여행 플래너 웹사이트를 구현하는 것을 목표로 합니다.

단순히 화면을 구성하는 것에서 그치지 않고, 사용자 입장에서 편리하게 여행 정보를 관리할 수 있도록 UI와 기능을 함께 고민하며 개발하고자 합니다.

## 📝 Notes

개인 프로젝트로 진행하며 웹 페이지의 레이아웃 구성부터 HTML 구조 작성, CSS 스타일링까지 직접 구현하고 있습니다.

앞으로 JavaScript를 활용한 동적 기능을 추가하고, 여행 등록부터 일정 및 메모 관리까지 실제로 동작하는 여행 플래너로 발전시킬 예정입니다.
